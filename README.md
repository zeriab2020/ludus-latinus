# Lūdus Latīnus

Latin vocabulary and grammar practice for *Lingua Latina per se Illustrata — Familia Rōmāna*, Chapters I–IV.

Modes: flashcards, quiz, ending drills, quick fill, Pēnsum A·B·C, say-it pronunciation practice, and a word list. Progress and coins are saved in the browser.

Open `index.html` in any browser, or use the GitHub Pages site.
